# LLMエージェント向け Excel / CSV 出力仕様

この文書は、Thermal Printer Web UI の Excel / CSV モードと連携する外部ソフトや LLM エージェントが、印刷用データファイルを自動生成するための仕様です。

目的は、感熱紙プリンタで大量の文字ラベルを安定して印刷できるように、LLM の出力を「人間が後から少し直す表」ではなく、このアプリへそのまま投入できる表形式ファイルにすることです。

## 対象ファイル形式

推奨形式は `.xlsx` です。CSV を出力する場合は UTF-8 の `.csv` としてください。

このアプリのアップロード UI は以下の拡張子を受け付けます。

- `.xlsx`
- `.xls`
- `.csv`
- `.tsv`
- `.txt`
- `.ods`

ただし、自動生成ソフトでは文字化け・改行・列順の安定性を優先し、原則として `.xlsx` を生成してください。CSV が必要な場合のみ UTF-8 CSV を使用してください。

## 基本構造

1行目はヘッダー行です。2行目以降の各行が、原則として1枚のラベルになります。

列の並び順は印字順です。アプリは各行の列を左から順に読み取り、ラベル本文を生成します。LLM エージェントは、印字したい順番で列を配置してください。

例:

| 商品名 | 数量 | 保管場所 | 備考 |
| --- | ---: | --- | --- |
| 感熱紙ロール | 12 | A-03 | 予備 |
| ラベルプリンタ | 1 | B-01 | 動作確認済み |

標準設定では、各行は次のような複数行テキストとして印刷されます。

```text
商品名: 感熱紙ロール
数量: 12
保管場所: A-03
備考: 予備
```

## 列名のルール

列名は短く、印刷されても意味が分かる名前にしてください。

推奨:

- `商品名`
- `氏名`
- `部署`
- `数量`
- `期限`
- `場所`
- `備考`
- `ID`
- `QR`

避けるべき列名:

- 長すぎる説明文
- 同じ意味の列名の重複
- 空白だけの列名
- 記号だけの列名
- `Loop` 以外でアプリ制御を期待する列名

`Loop` という列名は予約語です。大文字小文字は区別されません。`Loop`, `loop`, `LOOP` はすべて同じ制御列として扱われ、ラベル本文には印刷されません。

## 値のルール

各セルには、最終的に印刷したい文字列を入れてください。

推奨:

- 1セルあたり短い語句または短文にする
- 数値は必要な単位を含めるか、列名で単位が分かるようにする
- 日付は `YYYY-MM-DD` または `YYYY/MM/DD` のように曖昧でない形式にする
- 空欄にしたい項目は空セルにする

避けるべき内容:

- 長大な説明文
- Markdown 表記
- HTML
- JSON
- 箇条書き記号を多用した文章
- 印刷しない内部メモ
- LLM の説明文や前置き

## Loop 列

同じ行を複数回印刷したい場合は `Loop` 列を追加します。

例:

| 商品名 | 場所 | Loop |
| --- | --- | ---: |
| 感熱紙ロール | A-03 | 3 |
| ラベルプリンタ | B-01 | 1 |

この例では、`感熱紙ロール` のラベルが3回、`ラベルプリンタ` のラベルが1回印刷されます。

ルール:

- `Loop` は正の整数を入れます。
- 空欄、0、数値として解釈できない値は 1 として扱われます。
- `Loop` 列は印字されません。
- 大量印刷では、LLM エージェントは総印刷枚数が過剰にならないように必ず確認してください。

## セミコロン分割

セル内にセミコロン `;` を入れると、そのセルは複数のラベルに分割されます。

例:

| 氏名 | 食券 |
| --- | --- |
| 山田太郎 | 朝食;昼食;夕食 |

この行は、次の3枚のラベルとして展開されます。

```text
氏名: 山田太郎
食券: 朝食
```

```text
氏名: 山田太郎
食券: 昼食
```

```text
氏名: 山田太郎
食券: 夕食
```

複数列にセミコロンがある場合、同じ位置のセグメント同士が対応します。片方の列に該当位置がない場合は、その列の先頭セグメントが再利用されます。

例:

| 氏名 | 日付 | 食券 |
| --- | --- | --- |
| 山田太郎 | 2026-06-01 | 朝食;昼食;夕食 |

`日付` は3枚すべてで `2026-06-01` になります。

## セグメント内の繰り返し指定

セミコロン分割の各セグメントでは、末尾に `* 数字` を付けると、そのセグメントを複数回展開できます。

例:

| 氏名 | 食券 |
| --- | --- |
| 山田太郎 | 朝食 * 2;昼食;夕食 |

展開結果は `朝食`, `朝食`, `昼食`, `夕食` の4枚です。

ルール:

- `テキスト * 3` のように、末尾のアスタリスクと整数だけが繰り返しとして扱われます。
- `*` は半角を使ってください。
- 数字は正の整数にしてください。
- 繰り返し指定を印字したい文字として使う場合は、別の表現に置き換えてください。

## Loop とセミコロン分割の組み合わせ

`Loop` とセミコロン分割を同時に使うと、Loop 回数分だけセグメント一式が繰り返されます。

例:

| 氏名 | 食券 | Loop |
| --- | --- | ---: |
| 山田太郎 | 朝食;昼食 | 2 |

印刷順:

1. 山田太郎 / 朝食
2. 山田太郎 / 昼食
3. 山田太郎 / 朝食
4. 山田太郎 / 昼食

## 印刷レイアウトを考慮した出力方針

プリンタの印字幅は 384px です。長い値はアプリ側の自動折り返しや自動縮小で処理できますが、自動生成ソフト側でも短く整形することを推奨します。

LLM エージェントは次の方針で内容を作成してください。

- ラベル1枚あたりの情報量を少なくする
- 重要な項目を左側の列、つまり先に印字される列に置く
- 長い説明文は `備考` へまとめる
- `備考` はできれば20から40文字程度に抑える
- ID、番号、場所、期限など識別に必要な情報を優先する
- 人が見て即座に判断できる表記にする

## コンパクトモード利用時の考慮

アプリのコンパクトモードでは、複数の `列名: 値` が1行に詰めて配置されます。

コンパクトモードで使うファイルを生成する場合は、特に以下を守ってください。

- 列名を短くする
- 値を短くする
- 1行に載せたい情報だけに絞る
- 長い住所、説明文、複数文の備考を避ける

例:

| ID | 品名 | 数 | 棚 |
| --- | --- | ---: | --- |
| A102 | ロール紙 | 12 | A-03 |

## CSV 出力時のルール

CSV を出力する場合は以下を守ってください。

- 文字コードは UTF-8
- 1行目は必ずヘッダー
- 区切り文字はカンマ
- セル内にカンマ、改行、ダブルクォートが含まれる場合は CSV 標準に従ってダブルクォートで囲む
- セル内改行はできるだけ使わない
- セミコロン `;` はアプリの分割記号なので、通常の文章中では避ける

CSV 例:

```csv
商品名,数量,場所,Loop
感熱紙ロール,12,A-03,3
ラベルプリンタ,1,B-01,1
```

## LLM エージェントへの出力指示テンプレート

外部ソフトから LLM に依頼する場合は、次のような指示を使ってください。

```text
Thermal Printer Web UI の Excel / CSV モードで印刷するための表データを作成してください。

出力は .xlsx または UTF-8 CSV に変換可能な表形式にしてください。
1行目をヘッダー、2行目以降を印刷対象のラベル1枚分のデータにしてください。
列の順番は印字順です。
同じ行を複数回印刷する必要がある場合だけ、予約列 Loop に正の整数を入れてください。
セル内のセミコロン ; はラベル分割として扱われるため、分割したい場合以外は使わないでください。
セル内で「テキスト * 数字」の形式を使うと、そのセグメントが複数回印刷されるため、必要な場合だけ使ってください。
Markdown、説明文、JSON、HTML、内部メモは出力しないでください。
各セルは短く、感熱紙ラベルで読める文字量にしてください。
```

## 生成前チェックリスト

LLM エージェントまたは自動生成ソフトは、ファイル作成前に以下を確認してください。

- 1行目にヘッダーがある
- 空の列名がない
- 列順が印字順になっている
- `Loop` 列は必要な場合だけ使っている
- `Loop` の値が過剰でない
- セミコロン `;` を分割目的以外に使っていない
- `* 数字` を意図せず含むセルがない
- 各セルが短く、ラベルとして読める
- 総印刷枚数を計算し、ユーザーに確認できる
- CSV の場合は UTF-8 で保存している

## 総印刷枚数の考え方

総印刷枚数は、各行について次を計算して合計します。

```text
行の印刷枚数 = Loop 値 x その行で展開される最大セグメント数
```

セグメント内に `* 数字` がある場合は、展開後のセグメント数で数えます。

自動生成ソフトは、大量印刷の事故を防ぐため、総印刷枚数を作成完了画面や確認ダイアログに表示してください。

## 実装上の注意

現在のアプリは、アップロードされたブックの最初のシートを読み込みます。複数シートを作成しても、2枚目以降は通常の印刷対象として使われません。

そのため、自動生成ソフトは印刷対象データを必ず1枚目のシートに出力してください。補足情報、設定、ログ、プロンプトなどを同じブックに入れる場合は2枚目以降に置けますが、このアプリで印刷される前提にしないでください。

ファイル名には内容と日時を含めることを推奨します。

例:

```text
labels_inventory_2026-06-01.xlsx
labels_tickets_2026-06-01.csv
```
